# Shift At Midnight: разбор устройства игры (главный референс CLINIC 13)

Источник: локальный учебный проект `/Users/mac/Downloads/WebAIGames/ShiftMidnight` (экспорт Windows-сборки IL2CPP, Unity 6000.0.69f1). Изучено 2026-11-20 по YAML сцен, префабов, материалов, профилей и клипов, а также по сигнатурам скриптов.

**Правило использования.** Здесь описаны решения и числа своими словами. Их файлы, модели, текстуры, шейдеры и код в CLINIC 13 не переносим. Всё делаем с нуля, опираясь на приёмы и параметры.

**Ограничения разбора.**
- Тела методов C# пустые (IL2CPP), логика восстановлена по полям, данным и именам.
- Лайтмапы в экспорт не попали.
- Unity MCP не подключился: мост висит на HTTP-сервере 8080, а клиент Claude Code запускает свой stdio-сервер. Поэтому кадров из редактора нет.

## 1. Главный вывод о графике

Игра **не PSX-рендер**. Низкого внутреннего разрешения, пикселизации, экранного дизеринга, vertex snapping и аффинных UV нет. Ретро-вид собран из дешёвых и надёжных слоёв:

1. **Стандартный URP Lit** почти на всём: 734 из ~900 материалов.
   - 84% материалов полностью матовые (smoothness 0), металла нет.
   - Карты нормалей есть примерно у 30% материалов.
   - Эмиссия у ~160 материалов: вывески, экраны, лампы.
2. **Текстуры маленькие, с точечной фильтрацией.**
   - Point-фильтр у 1490 из 1664 текстур.
   - Типичный размер 64–512 px. Бетон 32×32, лица 128, тела 512, атлас магазина 1024.
   - Результат: хрустящий крупный тексель при полном разрешении экрана.
3. **Low-poly геометрия.**
   - Пропсы: медиана 125 треугольников, 90% до ~950.
   - Люди: 1–6 тыс. треугольников, скелет Mixamo.
4. **Запечённый свет и чёрный туман.**
   - 101 точечный источник, 31 прожектор и 2 направленных, все в режиме Baked, без реалтайм-теней.
   - Тёплый жёлтый `(1, 0.99, 0.70)`, бледно-красный `(1, 0.43, 0.42)`, тёмно-бордовый `(0.56, 0.2, 0.2)`, холодно-белый `(0.94, 0.98, 1)`.
   - Ambient трёхцветный и почти чёрный: небо 0, экватор `#1D2022`, земля `#0C0B09`.
   - Туман экспоненциальный², **чёрный**, плотность 0.01. Ночь просто «съедает» даль.
5. **Сильный SSAO** (renderer feature): интенсивность **16**, радиус 0.23, falloff 35, direct lighting strength 0.55. Отсюда тёмные контактные углы и «грязь» в стыках.
6. **Плёночная постобработка** (профиль Normal, глобальный):
   - Tonemapping Neutral, Bloom порог 0.8 и интенсивность 1;
   - Vignette 0.386 / 0.639; Film Grain тип Large01, интенсивность 0.325;
   - **Lens Distortion −0.2** (лёгкая «бочка», как у дешёвой камеры);
   - Color Adjustments: contrast +5, saturation +10.
7. **Обводка интерактивных объектов**: OutlineFx renderer feature, толщина 0.175, белая. Висит на мешах людей и предметов, включается при наведении.
8. **Декали URP**: кровь, лужи, граффити, грязь.
9. FXAA (high), Forward+, MSAA выкл., HDR вкл., тени основного света 1024, дальность теней 40 м.

**Итог «рецепта»:** матовый Lit + 64–256 px point-текстуры + low-poly + запечённые тёплые лампы в чёрном тумане + жирный SSAO + зерно / виньетка / бочка. Ретро-ощущение даёт текстура и пост, а не разрешение.

### Режимы постобработки (локальные Volume, меняются по событиям)

| Профиль | Назначение | Отличие от Normal |
|---|---|---|
| Normal | обычная смена | см. выше |
| CCTV | экраны камер | ACES, ч/б (saturation −99), зерно 1.0, хроматическая аберрация 0.23, дисторсия **+0.32** (подушка), виньетка 0.445 |
| Camera | фото / сканер | зелёный color filter `(0.22, 0.44, 0.13)`, contrast 100, bloom 10, зерно 1 |
| Blink | «очнулся» / удар / скример | bloom **50**, виньетка 1.0, дисторсия 1.0 со scale 2.15, хроматика 1, contrast 100 |
| Static | помехи | saturation −80, contrast 100, хроматика 0.55 |
| Drunk | опьянение | жёлтый фильтр, bloom 50, дисторсия 0.8, хроматика 1 |
| FinalSequence | финал | bloom 6 с красным оттенком, порог 0.6 |

Камеры наблюдения пишут в RenderTexture **480×270** (bilinear), видео катсцен — 1280×1000.

## 2. Камера и ощущение от первого лица

- FOV **80**, «присмотреться» (focus) — **38**, ближняя плоскость 0.1, дальняя 200.
- Скорость: ходьба 4, бег 7, присед 2.5, ползком при «downed» 1.4 м/с. Прыжок 6, гравитация 20, выносливость 10.
- Взаимодействие лучом на 3 м; «долгий взгляд» на 30 м (события «если посмотрел на…»).
- Покачивание головы — **клипы аниматора на держателе камеры**, а не код:
  - ходьба: период 1.17 с, Y +0.04 / −0.01, X ±0.023, крен ±0.2°;
  - бег: период 0.67 с, X ±0.03, Y до −0.034, крен ±0.4°;
  - урон: рывок углов ~6.6° / 4.9° / 6.3° за 0.28 с и возврат;
  - отдельные клипы: приземление, удар, выстрел, бросок, «работа руками».
- Отдача оружия: подъём −15°, кивок 5/5/−10, наклон 3°; сглаживание 0.05 с на удар и 0.25 с на возврат.
- Покачивание предмета в руке (sway) со сглаживанием поворота 20.
- Тряска камеры отдельным компонентом; в настройках есть переключатели тряски, покачивания и вспышек.

## 3. Архитектура

**Сцены:** Splash → EULA → PhotosensitivityWarning → LanguageSelect → MainMenu → Lobby → StartCutscene → **Game** → EODReport → EndMenu / EndingScenes. Отдельная Autosave.

**Стек:**
- **Photon Fusion** (State Authority = хост, RPC «хост → все»);
- Photon Voice (голос с близостью, громкость по игрокам);
- **A* Pathfinding Project** (AIPath + AIDestinationSetter, графы обновляются у дверей);
- Input System; Timeline для катсцен; VFX Graph только для электричества;
- остальные эффекты — Shuriken и паки WFX / CFX.

**Менеджеры главной сцены (синглтоны):**
- `EventManager`:
  - массив событий-UnityEvent по целочисленным индексам, всего до 120 ID (сюжетные флаги и письма);
  - каждое событие — RPC от хоста;
  - примеры: автобус конца дня, мигание света, грузовик, нашествие крыс и тараканов, лесные конечности, святилище, «подозрительный покупатель», двойник игрока.
- `HuntManager`:
  - фаза «охоты»: точки спавна, точка ухода, вентиляции, баррикады;
  - бюджет сложности монстров отдельно для соло и коопа;
  - полоса времени охоты;
  - монстры трёх уровней + «чёртик из коробки».
- `TransactionManager` (касса: карта, ID, звонок, сканер), `ShelfManager` / `RestockShelf`, `StoreManager`, `PurchaseManager` (магазин апгрейдов и оружия).
- `EODReportValues`: обязательная выручка 30 за день → отчёт в конце смены.
- `SpeakingManager` (субтитры + лог чата), `AmbientMusicSystem`, `SaveManager` (снапшоты объектов с «временем жизни в сменах»), `NuisanceCustomerManager` (хулиганы: граффити, моча, танцы, звонок).

**Данные посетителя — ScriptableObject (один на визит):**
- ID, префаб, флаг «двойник», «развлекательность», сложность 0–2;
- условия появления: кто должен быть жив, кто должен был прийти раньше, окно дней «после / до», фиксированный день или слот, доп. задержка.
- Так собран сюжет: один и тот же человек приходит в разные дни (Clyde Dawson 1/2/Final Day/Calendar Killer Night).
- У двойника свой ассет, сложность 1–2.

**Префаб посетителя (единый шаблон):**
- корень: диалог + поведение покупателя (обход полок по целям, очередь к кассе, терпение с полосой над головой, уход) + Hittable (здоровье 100, множители урона огнём / дробящим, объект смерти и объект попадания) + A* + сетевой объект;
- `GFXHolder` (аниматор-обёртка) → меш на скелете Mixamo;
- на меше: `MaterialFader` (появление за 1 с) и обводка;
- точки «откуда говорит», «откуда летят куски мяса»;
- скрытые объекты статусов: огонь, оглушение-электричество;
- три коротких звука (pick / switch / exit) со случайным pitch 0.9–1.1;
- canvas «ID Menu» с кнопками **HEAD / CLOTHES / LIMBS / MOVEMENTS**.

## 4. Система проверки и двойники (ядро, близкое к CLINIC 13)

Игрок смотрит на ID-карту: фото, подпись, имя. Сверяет её с внешностью и базой на компьютере («NET Database»), затем через меню выбирает, что проверить. Подсказка на карте вида «Verify: HEAD» говорит, куда смотреть.

**Как сделаны отличия двойника** (сверка 45 пар «оригинал / двойник», у 30 база не нашлась по имени):

| Тип приметы | Как реализовано | Примеры |
|---|---|---|
| Опечатка в имени | другой текст на бейдже | ANDAL → **ADNAL** |
| Правка текстуры | тот же меш и UV, перерисованный фрагмент | другие тату, родинка не там, сбрита борода, пропало витилиго, другой бейдж |
| Пропавший / лишний аксессуар | выключен или добавлен меш | нет шляпы, другая причёска (хвост вместо короткой) |
| Пропорции | масштаб кости или части | укороченное тело (Y 14.5 вместо 21), «чуть другой» рост |
| Движение | другой контроллер аниматора | дёргается голова, другая походка |
| Знание | другой диалог | ~20 двойников внешне идентичны, выдают себя ответами |
| Грубая подмена (поздние дни) | другой меш целиком | вместо человека — гномик, другое тело |

**Состояния персонажа** («Bloody ver», «Drunk ver», сломанная челюсть) тоже **текстура поверх той же развёртки**, без новой модели. Кровь, раны и обнажённое мясо дорисованы прямо в атлас.

**Портрет для ID:**
- рендер модели на светлой карточке, 512×512;
- головы отдельно, 128 px;
- 26 сменных текстур ртов (Mouth 1–26) + анимация «Mouth_Talk»: рот — декаль-текстура, которая меняется при речи;
- 121 вариант подписи (Sig1 1–121) — рукописные имена.

## 5. Монстры, ИИ и скримеры

**Общий шаблон монстра:**
- `EnemyHolder` (сеть) → тело с поведением, A*, Rigidbody;
- набор звуков с одинаковыми слотами: Attack, Roar, Jump, Interested, TakeDamage (массив), Leave, FootstepArray;
- pitch случайный 0.85–1.15, у «ухода» — 0.5–1.5;
- точка «середина тела» для прицеливания и эффектов;
- сфера-триггер, которая открывает двери;
- цепочка точек обхода `0, 0 (1)…`.

**Виды:**
- *Плачущий ангел* (Demented): скорость 9, движется только когда на него не смотрят, хруст костей.
- *Кукла-визгун* (2 уровня): маленький, скорость 4, ищет по «запаху».
- *Марионетка*: вылезает из «чёртика в коробке», если не докрутить ручку (удержание 1.5 с); здоровье 2000.
- *Паук-сущность* (3 уровня): плетёт кокон и откладывает яйца, «форма шёлка».
- *Догоняющий* (ChasingCreature): анимация «Zombie Scream» 1.3 с → бег 7.5, урон 10, «клинит оружие».
- *Убийца покупателей*: бежит к ближайшему NPC или игроку, бьёт, затем уходит к выходу и растворяется (MaterialFader).
- Сюжетные: монстр в мусорном баке (50 урона до реакции, сжимается при смерти, разбрасывает мясо), гость в туалете, девочка в вентиляции, камуфляж-монстр, «Дантист» с отдельными видео-вставками.
- Мирные: двойник игрока (берёт ник случайного игрока или друга из Steam!), 8 копий сотрудника, крысы и тараканы на счёт.

**Как сделан скример:**
1. У игрока под камерой стоит пустая точка «Jumpscare Goal».
2. Монстр со своим аниматором летит к ней с заданной скоростью и поворотом. На дистанции «snap» прилипает к точке и играет атаку прямо в камеру. Затем возвращается в «snapBack» или выключается.
3. Одновременно включается UI-объект «Blink»:
   - две чёрные полосы-века (верх и низ) за ~4 с расходятся до краёв;
   - локальный Volume «Blink» (bloom 50, виньетка 1, дисторсия 1, хроматика 1) уходит с веса 1 до 0;
   - получается вспышка-ослепление, потом медленное «открытие глаз»;
   - объект сам удаляется через 4–6 с.
4. Варианты: «HalfBlink» (помехи Static + удар), «Blink PistolShot», «SmallBlink», вспышка урона «Light TakeDamage» на 1 с.
5. Смерть (34 с):
   - через 1 с — затемнение за 0.33 с;
   - через 3.5 с проявляется «YOU DIED», звук нарастает;
   - через 11 с текст краснеет, щелчок, венок;
   - затем экран спектатора.
6. Табличка «YOU HAVE ALERTED THE ENTITY» — отдельный аниматор поверх HUD.

## 6. Кровь и VFX

**Цепочка крови:**
1. Попадание создаёт префаб частиц из двух систем:
   - «капли» (DeathParticles): 15–70 штук, жизнь 1.5–3 с, скорость 5–13, размер 0.2–0.3, гравитация 2, конус 40°, коллизии с миром;
   - «пыль-туман» (Spray): 200–300/с, 0.1–0.6 с, скорость 1–6, размер 1–2, гравитация −0.5 — облачко крови, всплывающее вверх.
   - Обе системы на lit-материале частиц, то есть кровь освещается лампами.
2. **Каждое столкновение капли спавнит лужу**:
   - URP-декаль 0.6×0.6×1.5, случайный масштаб 1–3.5, случайный поворот;
   - короткий всплеск собственных частиц;
   - звук со случайным pitch 0.2–1.5.
3. Обычная лужа: сетевой объект, отмывается шваброй, живёт **2 смены** в сохранении. Временная — гаснет аниматором и не отмывается.
4. Варианты: большие брызги; чёрная кровь (монстры); кровь насекомых; рвота; бензин; «яичная».
5. Куски мяса (голова, конечность, торс): простые меши мусора с физикой. Их можно подобрать и выбросить как мусор, тоже живут 2 смены.

**Остальные VFX:**
- огонь и дым (WFX / CFX, аддитивные Alpha8-текстуры), огнемёт и молотов;
- взрывы; электрическое поле оглушения (VFX Graph, флипбуки молний 6×6);
- частицы попаданий по кирпичу, бите, кувалде; дульные вспышки;
- мигание ламп — отдельное событие + скрипт мерцания света;
- паутина, прилипающая к экрану и стенам;
- «Blood Moon» — оверлей + материал неба.

## 7. Модели и текстуры

- Окружение — **модульные паки low-poly** (здания «SM_BLD», пропсы «SM_Prop», магазин, кафе). Один атлас 1024 px с палитрой и постерами на весь магазин. LOD у сложных стен и деревьев.
- Люди — стоковые полуреалистичные low-poly фигуры на Mixamo-скелете, 3–6 тыс. треугольников. Своя развёртка «AlbedoTransparency» 512 px и часто нормаль. Лица запечены в текстуру, рот — отдельная сменная текстура.
- Игрок — комбинезон 688 треугольников, голова 238, кисти отдельно. В третьем лице тело разделено на слои аниматора: ноги / торс / руки.
- Шапки и аксессуары — отдельные меши на кости головы (косметика за жетоны).
- Анимации людей — Mixamo:
  - Standard / Injured / Drunk / Old Man / Sass Walk, Zombie Scream / Crawl, Mutant Run;
  - Crazy / Swaying / Bored Idle, Grab Item;
  - головные анимации для «дёрганых» двойников.
- Звери — паки с полным набором: кошка, лабрадор, хаски, медведь, корова.
- Текстуры окружения часто 32–256 px: бетон 32, плитка и кирпич 256. Шум и грязь — отдельными декалями.

## 8. Звук и UI

- Звук: стоковые библиотеки (шаги по поверхностям, «ripping flesh» ×10, переломы, horror sweeps и stings, флуоресцентный гул, ветер, лес ночью) + оригинальная музыка (главное меню, отсчёт, погоня).
- Почти у каждого источника **случайный pitch**.
- UI:
  - пиксельные шрифты (VCR OSD Mono, Perfect DOS VGA 437, BoldPixels, PixelMplus, Pixel Operator);
  - мятая бумага для квоты и записок, пунктирные рамки, лупа;
  - кольцо-шкала обнаружения, слоты инвентаря;
  - почти всё анимируется аниматорами UI (fade, pop, flashing hint).

## 9. Что берём в CLINIC 13 (своими средствами)

| Решение Shift At Midnight | Аналог в CLINIC 13 |
|---|---|
| Полное разрешение + point-текстуры 64–256 px + матовый Lit | Тот же подход. Наш v3-зонд с 640×360 и дизерингом **отличается**: решить, оставить ли пикселизацию как свою черту или перейти на полное разрешение |
| Чёрный exp²-туман 0.01, почти чёрный ambient, запечённые тёплые лампы | Палата: тёплые лампы + бирюзовые дежурные, коридор тонет в чёрном |
| SSAO 16 / 0.23 | Обязательный AO, сильный |
| Зерно 0.33, виньетка 0.39, бочка −0.2, контраст +5 | Базовый профиль «Смена» |
| Локальные Volume-режимы (CCTV, Blink, Static, Drunk) | CCTV, «Пробуждение», «Помехи», «Бред / седация», «Отбой» |
| Подсказка «Verify: HEAD / CLOTHES / LIMBS / MOVEMENTS» | Карта пациента подсказывает зону осмотра |
| Двойник = правка той же текстуры / меша / анимации / текста | Наши `TellDef`: опечатка в карте, родинка, тату, зрачки, пропорции кости, походка, ответы |
| Состояния = текстура поверх той же UV | Наши «кровь / болезнь / мутация» тем же способом: 1 меш, N текстур |
| ScriptableObject визита с условиями дня | Наш `PatientArchetype` + расписание смен |
