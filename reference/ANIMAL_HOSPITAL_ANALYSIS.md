Дата: 2026-11-21.

**Игра:** Animal Hospital (Anomaly), разработчик Roytt / группа Animal Anomaly, вышла 10.05.2026, https://www.roblox.com/games/78515283254292/Animal-Hospital

**Источники.** Fandom-вики (`animal-hospital.fandom.com`) закрыта проверкой на ботов (403/402), прочитать её не удалось. Данные собраны из шести гайдов:

Метки: **[гайды]** — сходится в 2+ источниках; **[1 источник]** — данные только одного гайда; **[расх.]** — источники расходятся. Видео геймплея не смотрели.

## 1. Цикл

[гайды] Ночная смена в ветклинике, игроки за стойкой регистратуры.
1. Пациенты по одному подходят к окну.
2. Проверка по трём каналам: вживую, фото, камеры.
3. Пустить или опустить **красную рольставню** (отказ).
4. Принятых лечить в палатах мини-играми.
5. Параллельно — монстры по корпусу и аварии.

**Поражение:**
- рассудок (Sanity) падает до 0 [гайды];
- 3 смерти пациентов за смену [1 источник];
- по другому гайду игра бесконечная [расх.].

**Сложность** растёт с номером смены. Уровней и опыта нет.

| Смена | Что открывается |
|---|---|
| 1 | Без аномалий, обучение |
| 2 | Первые аномалии, NPC Barney |
| 3 | Магазин снабжения, огнетушитель и шокер |
| 4–5 | Скорая: 6+ пациентов разом [расх.] |
| 6 | Последний разбор главврача (Dr. Harlow) |
| 7+ | Нужна команда с ролями |
| ~10 | Особая «слизневая» смена [1 источник] |

**Деньги:** за смену платят наличными (для магазина) и монетами (для классов). Главврач ставит оценку и называет лучшего игрока.

## 2. Рассудок (Sanity) — ключевой ресурс

[1 источник, bloxguides] Старт около 61–65%. Пассивно теряется 1 пункт за 50 с. Ниже ~35% музыка замедляется, экран обесцвечивается.

| Событие | Рассудок |
|---|---|
| Посмотреть на проклятое фото | −10 |
| Ударить шокером настоящего пациента | −15 |
| Ударить шокером аномалию | +2 |
| Закончить операцию | +1 |
| Стоять в огне | −1…−3 в секунду |
| Ударить шокером коллегу | −2 обоим |
| Кофе | +15 |
| Шоколадка | +60 |
| Посмотреть на «Сталкера» | −10 |
| Схватил подкроватник | −10, затем −6 каждые 2 с |

## 3. Три канала проверки [гайды]

- **Вижу сам:** смотреть 4–5 с, потому что подёргивания и бегающий взгляд легко пропустить.
- **Фото:** камера → снимок проявляется на столе.
  - Взять снимок до проявки — минус рассудок.
  - Смотреть на «проклятое» фото — тоже минус.
  - Сверять по деталям с живым пациентом.
- **Камеры (CCTV):** 4 камеры — регистратура, лобби, палаты, экстренное отделение. Часть аномалий видна **только** на камере. Сломанную камеру чинят удержанием. Ещё есть переносная камера в кабинете.
- **Рекомендуемый порядок:** вживую → фото → камеры, открывать окно только если всё чисто. Ни одна проверка не ловит всех.

## 4. Аномалии пациентов → наши человеческие версии

| Animal Hospital | Канал | Признак | CLINIC 13 (человек, 1998) |
|---|---|---|---|
| Three Eyes | вживую | Третий красный глаз, голова следит | **«Третий глаз»:** родинка на лбу моргает. На ранних сменах — грубый признак |
| Hollow Face | вживую | Пустые глазницы, сутулится, дёргается | **«Пустоглазый»:** в окне в тёмных очках, на фото — пустые глазницы |
| Unnatural Grin / Crooked Face | вживую | Нарисованная улыбка, выпученные глаза, низкий искажённый голос | **«Улыбка»:** улыбается не переставая, голос в окне ниже, чем в рации |
| Human Teeth / Sharp Teeth | вживую | Человеческие зубы в звериной морде | **«Лишние зубы»:** когда говорит, видно два ряда зубов |
| Twitching | вживую / CCTV | Рывки головы или конечностей | **«Тик»:** дёргается только на камере сзади |
| Wandering Eyes / Staring | вживую / CCTV | Следит глазами, смотрит в камеру | **«Смотрит в объектив»:** на CCTV смотрит прямо в камеру |
| Changed Photo / Mismatched Ears | фото | Другой цвет, уши, глаза | **Несовпадение фото:** родинка, уши, причёска, серьга (наше правило несовпадения) |
| Cursed Photo | фото | Слишком реалистичное лицо, −10 рассудка | **«Проклятый полароид»:** на фото лицо врача, держащего снимок |
| Static Photo | фото | Помехи на снимке | **Засвеченный полароид** — автоматически аномалия |
| Black Bar Eyes | CCTV | Чёрная полоса на глазах | **«Цензура»:** на камере чёрная полоса на глазах |
| Boneless / Void Body | CCTV | Тянущееся или полностью чёрное тело | **«Тень»:** на камере вместо человека чёрный силуэт |
| Mismatching Face (камера) | CCTV | На камере другое лицо | **Другой человек на камере сзади** |
| Skinwalker (CCTV) | CCTV | Чёрная фигура с красными глазами, камера сама зумит | **«Наезд камеры»:** камера сама приближает лицо, надо быстро выключить |

**Если впустил аномалию** [гайды]:
- «ритуал смерти»: свечи, левитирующий пациент, таймер ~40 с;
- или из пациента вылезает монстр;
- или нападает Mimic.

Смерть аномалии не штрафуется, но смена приносит меньше денег.

**Наш вывод:**
- Сохраняем **правило несовпадения** (GDD §6.2) и добавляем к нему «грубые» признаки AH для первых смен.
- Таймер «ритуала» → наш **«приступ»** в палате: 40 с, лампы гаснут, пациент висит над кроватью. Двойника можно успеть изолировать.

## 6. Лечение и аварии

- **Диагноз** на экране: 1–3 нужных средства. Неверное лечение убивает пациента [1 источник]. У нас мягче: паника и повтор (GDD §7.3).
- **Средства AH → наши:**

## 7. Кооп, роли, классы

- **Роли** [гайды]: стойка + CCTV, лечение, «на подхвате». Голосовые сигналы вроде «глаза в регистратуре».
- **Взаимодействия:**
  - плюшевый мишка поднимает друга;
  - шокер по коллеге — −2 рассудка обоим, выстрел — −6;
  - «Обои» воруют предметы;
  - Barney просит кофе.
- **Игроков на сервер:** 4 или 30 [расх.]. У нас 1–4.
- **Классы** (10 штук, покупаются):

  | Класс | Бонус |
  |---|---|
  | Intern | +рассудок |
  | Nurse | +слоты инвентаря |
  | Secretary | +рассудок за приём |
  | Paramedic | газировка-ускорение |
  | Psychologist | эффекты рассудка ×2 |
  | Doctor | +рассудок за лечение |
  | Security | шокер |
  | Surgeon | бонус после лечения |
  | Head Nurse | +3 слота (за Robux) |
  | Secret Agent | пистолет (за Robux) |

  По 3 уровня у каждого.
- **Решение для CLINIC 13:**
  - В MVP классов нет.
  - После MVP можно ввести **«должности»** с одной мягкой бонусной способностью каждая: медбрат (+1 слот), санитар (быстрее каталка), охранник (шокер), психолог (+рассудок рядом).
  - GDD запрещает RPG-классы, поэтому финальное решение за Alex, после плейтеста.

## 8. Магазин и прогресс [1 источник, animal-hospital.me]

- Магазин снабжения открывается после смены 3. В нём 3 случайных товара, обновление каждые ~3 мин.
- **Товары:** кофе, шоколадка, газировка-ускорение, шокер на 1 или 3 заряда, пистолет, плюшевый мишка (поднять друга).
- **Улучшения на смену:** быстрее регистрация, +слот, быстрее компьютеры и ДНК, восстановление +25%, второе окно регистрации, автовыдача лекарств.
- **Бесплатно:** кофемашина (кулдаун 180 с), огнетушитель, шокер.
- **У нас:**
  - автомат с кофе и шоколадками «Сникерс» в комнате персонала;
  - шокер и разрядник вместо пистолета, оружия нет;
  - мишка → нашатырь;
  - улучшения — удобства, не бессмертие (GDD §14).

## 10. Что берём в CLINIC 13 (итог)

**Берём в MVP:**
1. Рольставня-отказ.
2. Три канала проверки.
3. Полароид, который нельзя трогать до проявки.
4. Рассудок как главный ресурс с цифрами AH для старта калибровки.
5. Кофе и шоколадка.
6. Подкроватник + сгущёнка.
7. «Стукач» в стекло + чай.
8. Двойник с пастью.
9. «Камера врёт».
10. Обморок и пожар с таймером.
11. Главврач по телефону с оценкой смены.

**После MVP:** Наблюдатель, Глазник, Обои, Фантом, Опухоль, скорая, магазин снабжения, должности, Геннадий и участковый, кот, особые смены.

**Не берём:**
- оружие;
- мгновенную смерть за неверное лечение;
- 30 игроков;
- покупку классов за реальные деньги;
- названия, модели, UI и реплики AH.

**Наши отличия:**
- люди вместо животных;
- 1998 год;
- полароид едет к кровати;
- второй шанс в палате;
- подменыш коллеги;
- ТВ-новости;
- стиль Shift.
