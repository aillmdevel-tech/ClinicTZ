## Ключевые решения

- **Animal Hospital** (Roblox) — главный референс механик. Берём: рольставню, 3 канала проверки, рассудок, монстров с контр-предметами, аварии с таймером, NPC. Адаптируем под людей и 1998 год.
- **Shift At Midnight** — главный референс стиля и трейлера. Стиль Shift: полное разрешение, point-текстуры, матовый Lit, туман, SSAO, зерно. PSX — только опция.
- Lethal Company — читаемая командная форма и кооп-юмор.
- Трейлер 60 с открывается ТВ-новостями с глитчами. Лиц и вебкамер друзей нет.
- Порядок разработки: персонажи → базовые механики → клиника → аномалии → новости и режиссёр → плейтест → трейлер → Steam.
- Стек: Unity 6.3 + URP, FishNet, MetaVoiceChat, Blender 5.2, Mixamo.
- Ничего не копировать из чужих игр: только решения.
